公开网页部署验收契约
====================

本目录属于独立、无敏感信息的静态验收网站。

发布要求：
1. 公开仓库与 GitHub Pages。
2. 根目录 index.html 可直接浏览。
3. HTML、CSS、JavaScript、SVG、PNG、JSON 和本文本保持原相对路径与原字节。
4. .nojekyll 由发布台补充，必须为空文件。
5. 不生成密文，不生成业务 Release，不需要业务后端。

源文件清单：
- index.html
- guide.html
- 404.html
- assets/styles.css
- assets/app.js
- assets/logo.svg
- assets/pixel-check.png
- assets/health.json
- docs/deployment-contract.txt

运行时检查：
- 首页显示 JavaScript“运行正常”。
- 首页和清单页显示静态 JSON“读取成功”。
- 首页按钮点击后计数增加。
- 主题按钮可切换页面配色。
- 第二页面、404 页面和本文件可直接访问。

本文件不包含账号、Token、密码、私钥、个人信息或业务秘密。
